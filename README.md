# 账单有数：邮件文件导入版

空白通用网页，任何人无需登录即可打开；不预置真实账单、邮箱或个人口令。首页“导入邮件文件”支持 EML、HTML 和 TXT。选文件后在浏览器本机解码、识别，再由用户核对保存。没有文件上传、邮箱连接或授权码输入，不需要 Render 或其他后台。

文件上限 2MB、正文上限 200000 字符，一次一份。EML 支持常见 multipart、Base64、quoted-printable 和字符集声明。HTML 仅提取文字，不渲染邮件或请求远程跟踪图片。PDF、MSG、图片和加密附件暂不支持；可粘贴文字或手动记录。不同银行识别字段需按原始账单核对，不能用最低还款或额度替代应还金额。

账单及已还标记保存在当前浏览器，不跨设备同步。清理浏览器数据或换设备前请导出 JSON 备份。每个人使用自己的浏览器；网站没有用户账户或云端账单库。托管平台仍可能记录访问 IP 等网络日志。

关闭网页后的还款提醒需生成 ICS 文件并导入个人日历、确认通知设置。网页标记已还不会自动删除已导入日历事件。没有每月自动读取新账单或后台推送。

部署当前静态网页不需要 Node 后台或邮箱凭据。仓库历史保留未启用的邮箱连接方案，但前端已不引用它，也不请求邮箱接口。不要启用该历史后台来运行文件导入版。

可将前端静态文件部署到 HTTPS 静态托管。具体手机、浏览器和网络的访问/日历效果需实机验证，不保证所有旧手机或所有大陆网络均可访问免费境外托管。
