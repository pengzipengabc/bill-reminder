# 账单有数：空白通用版

公开的静态网页工具。任何人都可打开，无需注册或登录。初始账本为空；不包含预置真实账单、邮箱、个人访问口令或任何加密个人账单文件。

每个人在自己的浏览器中导入、手动填写和保存账单。数据不上传、不跨设备同步；清理浏览器存储前应先导出备份。托管平台仍可能记录 IP 等访问日志。

功能：银行/其他银行选择、账单文字及 TXT/HTML/EML 导入核对、JSON 备份恢复、还款日/应还金额/最低还款展示、已还标记及 3/1/0 天提醒日历导出。示例数据只有主动点击“先看看示例”才显示，与真实记录分开。

没有自动邮箱同步和后台通知服务。网页通知只在网页运行时检查；关闭网页后的提醒需要导入自己的手机日历并确认通知权限。网页标记已还不会自动修改已导入的日历事件。

网页适配主流现代安卓与苹果浏览器，具体访问及通知效果需要实机和网络验证。GitHub Pages 免费静态托管不等于所有大陆网络均可访问。没有广告、统计脚本、远程字体或银行 API 调用。

可以将根目录的静态文件部署到 HTTPS 托管，不依赖 ChatGPT 或 Sites 服务。请不要把自己的备份、账单邮件、授权码或访问口令提交到这个公开项目中。
